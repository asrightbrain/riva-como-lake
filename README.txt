RIVA - static prototype (Bellano)

Open index.html in a browser to try it locally. If the stamps do not carry between pages
(some browsers restrict localStorage on file://), publish it as below.

To publish for free (static hosting, no server needed):
- Netlify: drag this whole folder onto the "Netlify Drop" page.
- Cloudflare Pages: create a project with "Direct upload" and select this folder.
- GitHub Pages: put the files in a repository and enable Pages on the main branch.
Check each service's current free-plan terms.

Feedback link: edit config.js and set feedbackUrl to your form (for example a Google Form).
The strip at the bottom of every page says the content is demo and texts are to be verified.

Files: index.html (home), see.html, eat.html, meet.html, street.html, passport.html,
riva-runtime.js (small template engine), config.js.
The mayor dashboard is NOT included: it uses invented data and should stay private.
